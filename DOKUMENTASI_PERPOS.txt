1. GAMBARAN UMUM PROJECT
================================================================================

Nama Project  : PERPOS (LibraSys)
Bahasa        : Python 3
Framework Web : Flask
Penyimpanan   : File JSON (sebagai pengganti database)
Antarmuka     : Web Browser (HTML + CSS + Jinja2 Template)

PERPOS adalah aplikasi sistem manajemen perpustakaan berbasis web. Sistem ini
memungkinkan dua jenis pengguna (Anggota dan Petugas) untuk berinteraksi dengan
data koleksi buku, transaksi peminjaman, pengembalian, dan reservasi buku.

Fitur Utama:
  - Login dan Logout berbasis sesi (session)
  - Manajemen buku (tambah, edit, hapus, cari)
  - Manajemen anggota dan petugas
  - Peminjaman buku dengan batas maksimum
  - Pengembalian buku dengan perhitungan denda otomatis (Rp 2.000/hari)
  - Reservasi buku dengan sistem antrean FIFO saat stok habis
  - Sinkronisasi status TERLAMBAT otomatis setiap request masuk
